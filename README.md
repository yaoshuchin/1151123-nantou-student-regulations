# 南投縣立南投國中 學生獎懲要點暨改過銷過辦法 數位查詢系統

本專案將「**南投縣立南投國中獎懲要點暨改過銷過辦法**」（114年1月20日校務會議通過）進行高精度 OCR 數位化建檔、Word 排版輸出，並開發為**響應式互動分類查詢 Web 應用系統**。

🌐 **線上網頁版**：經由 GitHub Pages 發布提供線上即時檢閱與試算。  
🔒 **系統通關密碼**：`049`（南投電話區碼）

---

## 🌟 系統功能亮點

1. **🔐 存取授權防護**
   - 內建通關密碼鎖定機制（密碼：`049`），保護校務法規資訊之存取安全。
   - 支援快速鎖定與 Session 記憶。

2. **🔍 互動分類與即時模糊搜尋**
   - **雙層分類篩選**：可依「獎勵措施（嘉獎/小功/大功）」或「懲處措施（警告/小過/大過）」快速過濾。
   - **情境主題標籤**：提供公物環境、常規秩序、拾金不昧、言行法紀、行動載具、違禁物品、校園暴力、性平與霸凌、交通安全等專屬標籤一鍵導覽。
   - **即時文字高亮**：輸入任何字詞即時標亮匹配段落，一秒定位特定規定。
   - **一鍵複製**：點選條文卡片即可自動複製該條項款內容，便利導師與學務行政人員填寫紀錄或獎懲通知單。

3. **⏱️ 改過銷過考察期 試算工具**
   - 依據第四條規定，依處分等級（警告滿3週、小過滿6週、大過滿9週）輸入處分公告日期，自動精確推算最快得申請改過銷過之民國年/西元年日期與剩餘倒數天數。
   - 內建申請標準作業流程（SOP）與三年級下學期除外限制提醒。

4. **📑 全文法規閱覽模式與檔案下載**
   - 提供法規公報正式版面排版，附原案行政審簽欄位。
   - 提供由 PDF 原稿精準排版輸出之 **Word (.docx)** 正式公文格式下載。
