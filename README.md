# 南投縣立南投國中 學生獎懲要點暨改過銷過辦法 數位查詢系統

本專案將「**南投縣立南投國中獎懲要點暨改過銷過辦法**」（114年1月20日校務會議通過）進行高精度 OCR 數位化建檔、Word 排版輸出，並開發為**響應式互動分類查詢與法規全文檢索 Web 應用系統**。

🌐 **線上網頁版**：經由 GitHub Pages 發布提供線上即時檢閱與試算。  
🔓 **免密碼開放檢索**：直接點開即可使用。

---

## 🌟 系統功能亮點

1. **🔎 全文檢索與多維分類查詢**
   - **全法規條文覆蓋**：檢索範圍擴充涵蓋法源依據（第一條）、獎勵措施（第二條）、懲處措施（第三條）、改過銷過程序與時限（第四條）、公佈實施（第五條）及行政簽核欄位。
   - **條文卡片檢索**：支援中文即時模糊搜尋、關鍵字黃底高亮，點選條文卡片即可自動複製該條項款內容。
   - **法規全文即時跳轉定位**：在法規全文閱覽區提供專屬檢索工具列，即時標註全文相符處，支援「上一處 / 下一處」平滑捲動跳轉與相符筆數統計。

2. **🏷️ 雙層分類與情境標籤導覽**
   - **雙層分類篩選**：可依「獎勵措施（嘉獎/小功/大功）」、「懲處措施（警告/小過/大過）」、「改過銷過章則」快速過濾。
   - **情境主題標籤**：提供公物環境、常規秩序、拾金不昧、言行法紀、行動載具、違禁物品、校園暴力、性平與霸凌、交通安全等專屬標籤一鍵速查。

3. **⏱️ 改過銷過考察期 試算工具**
   - 依據第四條規定，依處分等級（警告滿 3 週、小過滿 6 週、大過滿 9 週）輸入處分公告日期，自動精確推算最快得申請改過銷過之民國年/西元年日期與剩餘倒數天數。
   - 內建申請標準作業流程（SOP）與三年級下學期除外限制提醒。

4. **📑 全文法規閱覽模式與檔案下載**
   - 提供法規公報正式版面排版，附原案行政審簽欄位（依去識別化處理，姓名第 2 字以 O 替換）。
   - 提供由 PDF 原稿精準排版輸出之 **Word (.docx)** 正式公文格式下載。
